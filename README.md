# Natural Selection Software Homebrew tap

The Natural Selection Software Homebrew tap distributes
[NSS CLI](https://github.com/naturalselectionsoftware/nss-cli).
Requires Homebrew 7 or newer.

## Install

```sh
brew install naturalselectionsoftware/tap/nss
nss --version
```

## Upgrade

```sh
brew upgrade --cask naturalselectionsoftware/tap/nss
```

## Uninstall

```sh
brew uninstall --cask naturalselectionsoftware/tap/nss
```

See the [NSS CLI documentation](https://github.com/naturalselectionsoftware/nss-cli)
for configuration, usage, and supported platforms.
